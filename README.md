\# Single-Cycle RV32I CPU (in progress)



A single-cycle RISC-V processor written in Verilog, planning to implement on Digilent Basys 3 FPGA.



\## Status

\- \[x] R-type instructions (add, sub, and, or, slt), verified with a self-checking testbench in Vivado

\- \[ ] I-type (addi, lw)

\- \[ ] S-type (sw)

\- \[ ] B-type (beq)

\- \[ ] FPGA bring-up on Basys 3



\## Tools

Vivado (XSim) for simulation, RARS for assembling test programs.
